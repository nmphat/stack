# Conflict Resolution Prompts
# Used by stack-update.sh when git rebase fails.
# Each service has its own prompt with source of truth + customizations.
# Hermes agent reads these prompts to resolve conflicts automatically.
#
# Format: <service_name>|<prompt>
# Lines starting with # are comments.

harness-cloak|Git rebase conflict in ~/stack/harness-cloak.

Source of truth: browser-use/browser-harness upstream/main.
Our customization: CloakBrowser stealth mode integration (branch cloak).

Custom files to PRESERVE (keep ours):
- src/browser_harness/cloak.py — CloakBrowser auto-launcher
- src/browser_harness/daemon.py — ensure_cloak_browser() call + shutdown_cloak_browser()
- src/browser_harness/run.py — --cloak flag + updated HELP text
- pyproject.toml — renamed to harness-cloak, added cloak extras
- agent-workspace/domain-skills/cloakbrowser/anti-detection.md

Resolution rules:
1. For all OTHER files: accept upstream changes (source of truth)
2. For custom files above: if upstream also modified the same file, merge upstream changes INTO our customization (not replace it)
3. Specifically for daemon.py: upstream may add new functions — keep them, but ensure ensure_cloak_browser() and shutdown_cloak_browser() calls remain
4. Specifically for run.py: upstream may add new CLI flags — keep them, but ensure --cloak flag and HELP text remain
5. After resolution: run uv tool install -e ~/stack/harness-cloak --force to verify build

firecrawl|Git rebase conflict in ~/stack/firecrawl.

Source of truth: firecrawl/firecrawl main branch.
Our customization: PM2 wrapper + playwright-service simplifications (commit 381400c).

Custom files to PRESERVE (keep ours):

4. After resolution: run cd ~/stack/firecrawl && docker compose config to verify
